# MerchantMind｜AI 商家增长助手

一个面向中小商家的 AI 经营诊断产品。商家上传经营数据后，系统帮助回答三个问题：

1. 这一周的生意怎么样？
2. 哪个指标出现了问题，为什么？
3. 下周应该先做哪几件运营动作？

## 你正在做的第一版（MVP）

- 用模拟咖啡店数据展示经营看板
- 展示 GMV、支付转化率、复购率、外卖好评率
- 根据数据规则发现经营异常
- 将异常转为清晰的 AI 运营建议

## 项目文件怎么理解

| 文件 | 它负责什么 |
| --- | --- |
| `app/page.tsx` | 页面内容和点击交互：产品的“骨架与行为” |
| `app/globals.css` | 配色、排版、卡片样式：产品的“外观” |
| `data/` | 商家经营数据样例：产品的“事实依据” |
| `README.md` | 产品目标、范围和开发记录：你的“项目说明书” |

## 第一周结束时你应能讲清楚

“我在做一款 AI 商家经营诊断工具。它将经营数据转为异常提醒、原因解释和行动建议，帮助商家更快完成经营复盘。”

## 不做什么

第一版不做真实支付、不接入外卖平台、不保存真实用户信息。我们先把数据分析与 AI 决策闭环做扎实。
